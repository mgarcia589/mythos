# Spec: Form 8858 Support in Mythos

## Outcomes

1. Mythos can parse IRS Form 8858 (Information Return of U.S. Persons With Respect
   To Foreign Disregarded Entities and Foreign Branches) from e-file XML
2. ReviewEngine runs automated checks on 8858 data (completeness, flow, reasonableness, rollover)
3. Reports compare PY vs CY for 8858 entities (balance sheet, E&P, entity changes)
4. CLI and API support `--form 8858` to target FDE/FB analysis
5. Combined 5471+8858 export in a single Excel workbook for full-picture review

## In-Scope

### Form 8858 Schedules

| Schedule | Purpose | Key Fields |
|----------|---------|------------|
| Main form | FDE/FB identification | Name, EIN, ref ID, country, currency, tax owner, dormant indicator |
| Schedule C | Income statement | 15 line items, each with FC + USD amounts |
| Schedule F | Balance sheet | 6 lines (BOY/EOY): cash, other assets, total assets, liabilities, equity, total |
| Schedule G | Other information | 14 boolean indicators (Pillar Two, DCLS, base erosion, etc.) |
| Schedule H | Current E&P | Net income, additions/subtractions, current E&P, DASTM, FX rate |
| Schedule M | Related-party transactions | 4 counterparty groups × 10+ transaction types (SIBLING element) |

### Entity Identification

- Primary key: `ForeignEntityIdentificationGrp/ForeignEntityReferenceIdNum`
- Entity name: `FDEOrFBName/BusinessNameLine1Txt`
- Country: `CountryEntityOrgDetail/CntryUnderWhoseLawsOrganizedCd`
- Functional currency: `FunctionalCurrencyCd`
- Tax owner: `TaxOwnerName/BusinessNameLine1Txt` + `TaxOwnerEntityIdGrp/ForeignEntityReferenceIdNum`
- Category: `FDEUSPersonInd` (US person FDE) or `FBCFCInd` (FB of CFC)
- Dormant: attribute `summaryDormantFDECd` on `<IRS8858>` element

### Schedule C Nesting Pattern

```xml
<!-- Non-USD functional currency -->
<GrossReceiptsOrSalesIncmStmt>
    <FunctionalCurrencyAmt>1000000</FunctionalCurrencyAmt>
    <USDollarAmt>750000</USDollarAmt>
</GrossReceiptsOrSalesIncmStmt>

<!-- USD functional currency (no FC child) -->
<GrossReceiptsOrSalesIncmStmt>
    <USDollarAmt>558316773</USDollarAmt>
</GrossReceiptsOrSalesIncmStmt>
```

### Schedule F Nesting Pattern

```xml
<CashAndOtherCurrentAssets>
    <BeginningAmt>101070118</BeginningAmt>
    <EndingAmt>111817697</EndingAmt>
</CashAndOtherCurrentAssets>
```

### Schedule M Location

Schedule M is a **sibling** of `<IRS8858>`, NOT a child. Linked via `referenceDocumentId`:
```xml
<ReturnData>
  <IRS8858 documentId="8858-001" referenceDocumentId="8858M-001">...</IRS8858>
  <IRS8858ScheduleM documentId="8858M-001">...</IRS8858ScheduleM>
</ReturnData>
```

### Automated Checks (20 total)

**Completeness (CMP-8858-001 to CMP-8858-005)**
- CMP-8858-001: FDE in return but no Schedule C (income statement missing)
- CMP-8858-002: FDE in return but no Schedule H (E&P missing) — skip dormant
- CMP-8858-003: FDE in return but no Schedule F (balance sheet missing) — skip dormant
- CMP-8858-004: Non-dormant FDE without functional currency
- CMP-8858-005: No exchange rate on Sch H for non-USD entity

**Flow (FLO-8858-001 to FLO-8858-008)**
- FLO-8858-001: Sch C net income ≠ Sch H line 1 (net income per books)
- FLO-8858-002: Sch F total assets ≠ cash + other assets
- FLO-8858-003: Sch F total liab+equity ≠ liabilities + owner equity
- FLO-8858-004: Sch F total assets ≠ total liabilities + owner equity (A=L+E)
- FLO-8858-005: Sch C total income ≠ sum of income lines
- FLO-8858-006: Sch H current E&P ≠ net income + additions - subtractions
- FLO-8858-007: Sch H USD E&P ≠ FC E&P × exchange rate (within 1%)
- FLO-8858-008: Sch C gross profit ≠ gross receipts - COGS

**Reasonableness (RSN-8858-001 to RSN-8858-004)**
- RSN-8858-001: Exchange rate outside 0.01–100 range
- RSN-8858-002: Total assets = 0 for non-dormant FDE
- RSN-8858-003: Revenue > 0 but net income < -200% of revenue (extreme loss)
- RSN-8858-004: E&P in USD but no exchange rate populated

**Rollover (ROL-8858-001 to ROL-8858-003)**
- ROL-8858-001: Entity in PY but dropped from CY (without liquidation)
- ROL-8858-002: New entity in CY not in PY (informational)
- ROL-8858-003: Sch F EOY(PY) ≠ BOY(CY) — balance sheet discontinuity

### Reports (5 total)

| Report | Description |
|--------|-------------|
| 8858 Sch F Rollover | BOY/EOY per entity, PY EOY vs CY BOY tie |
| 8858 E&P Summary | Sch H detail: net income, additions, subtractions, current E&P, FX |
| 8858 Income Statement | Sch C top-line: revenue, COGS, gross profit, deductions, net income |
| 8858 Entity Changes | New/dropped FDEs between PY and CY |
| 8858 Tax Owner Map | FDE → Tax Owner relationship with country + currency |

## Out-of-Scope

- Schedule M detailed transaction analysis (Phase 2 — complex counterparty matching)
- Schedule I (minimal: single boolean field, no meaningful checks)
- Schedule J (often empty in practice — `<TotFrgnIncmTaxesPaidAccruedGrp/>`)
- Cross-form ties between 5471 and 8858 (Phase 2 — e.g., CFC income includes FDE income)
- Form 8865 (foreign partnerships) — separate future spec
- XBRL validation or schema conformance checking

## Constraints

- Python 3.10+, pandas, lxml (same stack as 5471)
- All field maps in `lab/xml_parser/field_maps.py` — append, don't restructure
- Check IDs follow pattern: `{CAT}-8858-{NNN}` to distinguish from 5471 checks
- Column naming convention: `IRS8858{Schedule}_{ChildTag}` (parallel to 5471)
- Dormant FDEs (`summaryDormantFDECd` attribute) excluded from most checks
- Reports use same `RolloverReport`/`RolloverItem` models as 5471
- Parser must handle both USD-functional (no FC child) and non-USD (FC+USD) patterns
- Schedule M extraction requires sibling lookup by `referenceDocumentId`

## Prior Decisions

- Parser uses recursive `_flatten_element()` — works generically for 8858 too
- `extract_form("IRS8858ScheduleC")` already works mechanically via existing parser
- Entity info extraction needs separate function (different tags than 5471)
- ReviewEngine dispatches by form type: `form_type` parameter on `review()`
- `CheckContext` pattern is form-agnostic — reused for 8858 checks
- `safe_float()` helper works unchanged
